## 验收与测试场景

| 场景 | 可判定结果 |
|---|---|
| 外网 user 从注册到带引用问答、转人工、反馈 | 完整旅程成功，agent 接单回复、admin 处理反馈和查看统计可核对 |
| 用户跨账号/知识库猜测 ID 或下载链接 | 历史、检索、引用和文件下载均拒绝越权，没有内容泄露 |
| 云模型超时、worker 重启、浏览器断线 | 可理解错误/取消状态、任务可恢复；无重复完整回答或重复入库 |
| 从真实备份恢复至隔离环境 | 用户/会话/文件/有效向量版本可用，抽样下载和问答通过 |
| 部署错误版本后按预案回退 | 恢复预期健康与功能，版本/数据边界有记录，不以删除卷解决问题 |
